## 1. Цель шага

Поднять рабочий каркас нового OstapMemory в Docker так, чтобы:
- по клику на существующий ярлык на рабочем столе открывался новый стек;
- старый Open Notebook был полностью заменён (те же порты);
- бэкенд переехал в `OM/`, фронт начался заново на Vue 3.

Интерфейса с ячейками на этом шаге ещё нет — это ФАЗА 1+.

## 3. Что сделано (7 шагов)

### 3.1. Backend перенесён в `OM/`
Скопированы из `repo/`:
- `api/` — FastAPI приложение
- `open_notebook/` — доменный слой (включая миграции, в т.ч. 16 и 17)
- `commands/` — командный слой (импортируется роутерами API)
- `prompts/` — шаблоны промптов
- `data/` — рабочая папка (старое langgraph-состояние и uploads вычищены для чистого старта)
- `pyproject.toml`, `uv.lock`, `run_api.py`

### 3.2. Новый фронт Vue 3
Создан `OM/frontend/`:
- Vue 3.5 + Vite 6 + TypeScript
- Pinia, заготовки под vue-router и lucide-vue-next
- Страница-заглушка `App.vue`: заголовок «OstapMemory», подпись «Vue 3 каркас работает — ФАЗА 0» и индикатор живости бэкенда

### 3.3. shadcn-vue + Tailwind
- `tailwind.config.js`, `postcss.config.js`, CSS-перементемы (light/dark) в `src/assets/index.css`
- `components.json` (конфиг shadcn-vue), хелпер `cn()` в `src/lib/utils.ts`
- Локальная сборка фронта проходит чисто (`npm run build` — 0 ошибок)

### 3.4. Dockerfile'ы
- `OM/Dockerfile.backend` — только Python/FastAPI (без Next.js), uv, предзагрузка tiktoken, запуск на 0.0.0.0:5055
- `OM/frontend/Dockerfile` — dev-режим Vite (hot-reload); prod-сборку с nginx добавим на этапе polish

### 3.5. docker-compose
`OM/docker-compose.yml` — 3 сервиса:
- `surrealdb` :8000, том `./surreal_data`, namespace/database `ostap_memory`
- `backend` :5055, env SurrealDB + ключ шифрования, том `./data`
- `frontend` :8502, проксирует `/api` на `backend:5055`

### 3.6. Страховка и правила
- `OM/component-templates/` — папка эталонных компонентов (пока пустая, с README)
- `OM/CLAUDE.md` — рабочие правила: русский язык, verify-перед-сдачей, стоп-правила

### 3.7. Ярлык
`scripts/start_ostap.sh` переключён на `docker compose -f OM/docker-compose.yml up -d`, пауза увеличена под старт Vite.

## 4. Проблемы, пойманные и устранённые при проверке

| Проблема | Причина | Решение |
|---|---|---|
| Сборка backend падала: `open_notebook/__init__.py not found` | Файл был удалён в рабочей копии `repo/` (в git присутствует) | Восстановлен из git в `OM/` |
| `vue-tsc` ошибки на `node:url` в `vite.config.ts` | Не хватало типов Node | Добавлен `@types/node` + `types: ["node"]` в tsconfig.node |
| `uv sync` обрывался | Нестабильная/медленная сеть окружения | Повтор сборки (uv делает retry), слои закэшировались |
| Backend падал: `ModuleNotFoundError: No module named 'commands'` | Папка `commands/` не была скопирована | Скопирована, backend пересобран |
