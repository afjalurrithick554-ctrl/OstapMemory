# Отчёт: ФАЗА 3 — Источники и Заметки, OstapMemory (Vue 3)

**Дата:** 2026-06-28
**Статус:** ✅ Собрана и проверена (визуальный прогон в браузере — за пользователем)
**Объём:** наполнение колонок Источники и Заметки в детальной странице ячейки + управление контекстом ИИ. Чат — Фаза 4.

---

## 1. Цель шага

Заменить заглушки колонок «Источники» и «Заметки» в детальной странице ячейки на рабочий
функционал: добавление/просмотр/удаление источников (ссылка/файл/текст), CRUD заметок с
markdown, и управление тем, что входит в контекст ИИ (для будущего чата в Фазе 4).
Бэкенд (`/api/sources`, `/api/notes`, `/api/notebooks/{id}/context`) уже был скопирован
в ФАЗЕ 0 — правок логики не требовал.

---

## 2. Принятые решения (согласованы с пользователем перед сборкой)

| Вопрос | Решение |
|---|---|
| Обработка источников | **Асинхронно + поллинг** статуса (`async_processing=true`, опрос `/sources/{id}/status` каждые 3 с, пока статус new/queued/running) |
| Глобальная вкладка `/sources` | **Не трогаем** — остаётся заглушкой до Фазы 5 (поиск). В Фазе 3 только колонка внутри ячейки |
| Редактор заметок | **Простой**: textarea + переключатель «Правка/Просмотр» через `markdown-it` |
| Хранение контекста | `localStorage` по `notebook_id` (Pinia-стор `context`). Чат (Фаза 4) прочитает готовый `ContextConfig` |
| Оценка токенов | По кнопке (не на каждое переключение), чтобы не дёргать API |

---

## 3. Что сделано

### Backend
- Логику не меняли. **Добавлен недостающий сервис `worker`** в `docker-compose.yml` —
  воркер очереди команд `surreal-commands-worker` (импортирует `commands.source_commands`,
  `embedding_commands`, `podcast_commands`). Без него источники с `async_processing`
  зависали в статусе `new` навсегда (латентный пробел из Фаз 0–2, всплыл при verify).

### Frontend (новый код)
- **Типы**: `types/source.ts`, `types/note.ts`, `types/context.ts` (уровни контекста — строки,
  которые парсит backend: `not in` / `insights` / `full content`)
- **API-клиенты**: `api/sources.ts` (multipart-форма на создание), `api/notes.ts`, `api/context.ts`
- **Композаблы** (`@tanstack/vue-query`): `useSources.ts` (с `refetchInterval` — поллинг, пока
  есть источник в обработке), `useNotes.ts`
- **markdown**: `lib/markdown.ts` (`markdown-it`, `html:false` — защита от XSS) +
  стили `.md-body` в `assets/index.css` (компактный рендер без typography-плагина)
- **Стор контекста**: `stores/context.ts` — уровни include/exclude по каждой ячейке,
  персист в localStorage, `buildConfig()` достраивает дефолтами для API
- **Колонка источников**: `SourcesColumn.vue`, `SourceCard.vue` (тип по asset, статус
  обработки, бейдж инсайтов/индекса, меню удаления, переключатель контекста),
  `AddSourceDialog.vue` (вкладки ссылка/файл/текст, чекбокс эмбеддинга),
  `SourceDetailDialog.vue` (полный текст + инсайты)
- **Колонка заметок**: `NotesColumn.vue`, `NoteCard.vue` (бейдж human/ai, превью),
  `NoteEditorDialog.vue` (textarea + переключатель Правка/Просмотр)
- **Контекст**: `context/ContextToggle.vue` (универсальный сегментный переключатель уровня),
  `context/ContextSummaryBar.vue` (сводка «сколько включено» + оценка токенов по кнопке),
  **bulk-действия** «всё в/из контекста» в каждой колонке
- **Детальная страница** `NotebookDetailView.vue`: заглушки колонок Источники/Заметки
  заменены реальными колонками, сверху добавлена панель контекста. Колонка «Чат» — Фаза 4
- **Локали** ru+en: секции `sources`, `notes`, `context`
- **Эталоны** `component-templates/`: `SourceCard.vue`, `NoteCard.vue`, `ContextToggle.vue`

## 4. Проблемы, пойманные и устранённые при проверке

| Проблема | Причина | Решение |
|---|---|---|
| **Источник вечно в статусе `new`** | Не был запущен воркер очереди команд — бэкенд поднимал только API (`run_api.py`) | Добавлен сервис `worker` в docker-compose; зависшая команда тут же обработалась (0.18с) |
| **`markdown-it` не виден в контейнере фронта** | Анонимный том `/app/node_modules` от старого контейнера затенял свежий образ | `docker compose up -d --force-recreate --renew-anon-volumes frontend` |
| Tooltip падал бы на пропе `content` | У компонента Tooltip проп называется `label` | Исправлено на `:label` |
| `prose`-классы не дали бы отступов | typography-плагин не установлен | Свои стили `.md-body` в index.css (работают с `v-html`) |

## 6. Открытые вопросы (на будущее)

- **Генерация инсайтов** (запуск трансформаций на источнике) — UI не делали: завязано на
  трансформации (Фаза 5) и модели ИИ. Детальный диалог источника показывает инсайты,
  если они есть, но не запускает генерацию.
- **Детальная страница источника** сделана как диалог внутри ячейки, не отдельным роутом —
  достаточно для Фазы 3; отдельный роут можно добавить вместе с глобальной `/sources` в Фазе 5.
- Удаление источника/заметки — через `confirm()`; диалог-подтверждение с превью можно добавить позже.
- Контекст-состояние в localStorage переживёт перезагрузку; синхронизацию между вкладками
  браузера не делали (не требуется).
- Фронт по-прежнему в dev-режиме (Vite). Prod-сборка (nginx) — на этапе polish.
