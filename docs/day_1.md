# OstapMemory: План реализации (TES1-26)

## Концепция продукта (Vision)
**OstapMemory** — это универсальный модуль долгосрочной памяти для AI-агентов (OpenCode, OpenCloud, AntiGravity и др.), который одновременно является визуальным инструментом управления проектами для пользователя. 

Продукт решает проблему «потери контекста» у агентов: пользователю не нужно каждый раз заново объяснять агенту, на чем они остановились вчера. Агент имеет постоянный доступ к актуальному состоянию проекта через базу данных, которая для пользователя выглядит как интуитивно понятная Kanban-доска.

## Целевая аудитория
Пользователи, работающие с AI-агентами (разработчики, менеджеры, криэйторы), которые хотят использовать агентов максимально эффективно, но не хотят или не могут тратить время на сложную техническую настройку.

## Архитектура и механика работы
1. **Контейнер:** Система разворачивается локально (ПК/ноутбук) или на сервере пользователя (через Docker). Поддерживается **многопользовательский режим**.
2. **База данных:** Единое хранилище информации, метаданных, задач и отчетов.
3. **Пользовательский интерфейс (UI):** Визуальная Kanban-доска. Столбцы (статусы), карточки (задачи), стикеры, теги — всё это метаданные базы.
4. **Секция отчетов:** Внутри карточек задач выделена отдельная системная секция для агентов, куда они пишут свои логи и результаты работы. Это не смешивается с пользовательским описанием.
5. **Автоматизация:** Работа агентов максимально заскриптована и формализована, исключая самодеятельность. Агент работает по строгим правилам и "видит" ситуацию через API.

## Утвержденный технологический стек
- **База данных:** `SQLite` + ORM (Prisma или Drizzle). *Масштабируемость: SQLite внутри Docker легко выдержит работу небольшой команды (тысячи задач). При росте нагрузок или необходимости кластеризации благодаря ORM мы сможем переключиться на PostgreSQL буквально за пару часов изменения конфигурации.*
- **Бэкенд (API):** `Node.js (TypeScript)` + `Nitro (Nuxt)`. 
- **Интерфейс (Frontend):** `Nuxt 3` + `TailwindCSS`. 
- **Интеграция с агентами:** **MCP Server (Model Context Protocol)**.
- **Доставка:** `Docker Compose` (изолированный контейнер с авторизацией пользователей).
