# Система Тегов и Стикеров (Архитектура Табло)

В этом документе описывается система тегов (метаданных) для карточек задач. Теги служат визуальными маркерами для человека на фронтенде (Vue 3) и жесткими триггерами поведения для ИИ-агента.
*Примечание: данный базовый набор тегов зафиксирован на раннем этапе (TES1-43) и будет расширяться в ходе тестирования реального взаимодействия.*

## 1. Категория: Управление поведением ИИ
Эти теги напрямую говорят агенту, как именно он должен работать с карточкой.

| Название тега | Цвет / Иконка (Vue 3) | Логика поведения ИИ-агента |
| :--- | :--- | :--- |
| **`Автопилот`** | 🟢 Зеленый / `🤖` | **Полная свобода:** Агент может сам взять карточку из «Готово к работе», выполнить её от начала до конца, написать тесты, собрать сборку и перевести дальше по доске без промежуточных согласований. |
| **`Совместно`** | 🔵 Синий / `💬` | **Парное программирование:** Агент выполняет задачу строго по шагам и запрашивает подтверждение пользователя перед следующим шагом. |
| **`Требует ревью`** | 🟣 Фиолетовый / `👀` | **Остановка перед пушем/мержем:** Агент выполняет работу, но перед финальным сохранением кода обязательно останавливается и зовет пользователя. |
| **`Блок / Ждет`** | 🟡 Желтый / `✋` | **Жесткий блок:** Агенту строго запрещено взаимодействовать с задачей (писать код, менять статусы), пока тег не будет снят человеком. |

## 2. Категория: Контекст задачи
Помогают визуально отфильтровать доску и задают агенту правильный "настрой" (system prompt).

| Название тега | Цвет / Иконка (Vue 3) | Влияние на ИИ-агента |
| :--- | :--- | :--- |
| **`Архитектура`** | 🟤 Коричневый / `🏗️` | **Режим планирования:** Агент не пишет программный код, а работает с `.md` файлами, диаграммами и проектированием БД. |
| **`Баг`** | 🔴 Красный / `🐞` | **Режим дебаггера:** Приоритет логам и тестам. Код пишется только ради фикса ошибки, запрет на добавление новых фич. |
| **`Фича`** | циановый / `✨` | **Стандартный режим:** Написание новой функциональности по ТЗ. |
| **`Рефакторинг`** | ⚪ Серый / `🧹` | **Только чистота кода:** Строгий запрет на изменение бизнес-логики. Допускается только форматирование, оптимизация и типизация. |

## 3. Категория: Приоритет

| Название тега | Цвет / Иконка (Vue 3) | Логика поведения ИИ-агента |
| :--- | :--- | :--- |
| **`Срочно`** | 🟠 Оранжевый / `🔥` | **Перехват фокуса:** Если ИИ свободен, он берет эту карточку первой из колонки «Готово к работе», игнорируя порядок остальных. |

## Визуальное представление (Frontend Vue 3)
*   **Стиль:** Компактные "таблетки" (pills) со скругленными краями (`border-radius: 9999px` в Tailwind).
*   **Динамика:** Тег `Срочно` может иметь легкую пульсирующую обводку.
*   **Ограничения:** На одной карточке рекомендуется отображать не более 3-4 тегов для минимизации визуального шума.
