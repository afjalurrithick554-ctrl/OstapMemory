# OstapMemory Context Updater

## Когда активируется
Триггеры:
- `/update_context`
- "обнови контекст"
- "зафиксируй результаты"
- "зафиксируй сессию"

## Алгоритм работы

### Шаг 1: Анализ сессии
Определи, что было сделано в текущем сеансе:
- Какие фичи добавлены / изменены
- Какие баги исправлены
- Какие рефакторинги проведены
- Какие решения приняты
- Текущие статусы компонентов / модулей

### Шаг 2: Чтение контекста
Прочитай файл: `/home/boba/repos/OstapMemory/repo/docs/PROJECT_CONTEXT.md`

Раздели содержимое на блоки (Features, Bug Fixes, Architecture, TODO, etc.)

### Шаг 3: Обновление
Интегрируй информацию о сессии:
- **Добавь** новые факты в релевантные секции
- **Обнови** статусы существующих пунктов
- **Удали** устаревшую информацию (если что-то завершено / больше не релевантно)
- **Переформулируй** неточные описания

### Шаг 4: Коммит
После обновления файла:
```bash
git add repo/docs/PROJECT_CONTEXT.md
git commit -m "docs: Обновлен PROJECT_CONTEXT.md с результатами сессии"
```

## Правило автоматизма
✅ Делает git commit **АВТОМАТИЧЕСКИ** (без запроса пользователя)

⚠️ ИСКЛЮЧЕНИЕ: Если пользователь сказал "подожди с коммитом" — жди явного разрешения

## После коммита
Покажи краткий отчёт:
- Что добавлено / изменено в контексте
- Сколько строк изменилось
- Сообщение коммита

## Примеры обновления

### До
```markdown
## Features
- Cell types: basic structure
```

### После
```markdown
## Features
- Cell types: full hierarchy (Epic, Task, Subtask) with state machine
- Cell rendering: dynamic based on type
```
