# UI Feedback Tracker

## Когда активируется
Используется явно (пользователь просит: "посмотреть комментарии", "проверить feedback", или `/ui-feedback`), или срабатывает на упоминание UI_FEEDBACK.md.

## Алгоритм работы

### Фаза 1: Просмотр
1. Прочитай `/home/boba/repos/OstapMemory/repo/UI_FEEDBACK.md`
2. Распарсь невыполненные замечания (начинаются с `[ ]`)
3. Покажи пользователю список открытых задач с кратким описанием

### Фаза 2: Ожидание подтверждения
- Дождись явного ответа пользователя: какие задачи он хочет делать или делает
- НЕ начинай работать без согласия

### Фаза 3: Выполнение и отметка
- **КРИТИЧЕСКОЕ ПРАВИЛО**: Отмечать как выполненную (`[x]`) можно **ТОЛЬКО ПОСЛЕ** того, как:
  - Код изменён в файле
  - Изменение протестировано (если нужно)
  - Пользователь подтвердил завершение
  
- Отметку делай последней операцией в Edit на UI_FEEDBACK.md
- В сообщении указывай: какие задачи закрыл, какие остались

## Примеры отметки

❌ **Неправильно**: отметить до кода
```markdown
[x] Добавить кнопку (я ещё не добавил, но планирую)
```

✅ **Правильно**: отметить после кода
```markdown
[x] Добавить кнопку (уже добавлена в Button.tsx, протестирована)
```

## Автоматизация
Этот скилл НЕ делает автоматически. Работает по запросу пользователя.
